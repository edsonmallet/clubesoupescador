# @clube/mobile

Expo + Expo Router app for the Clube platform. Part of the `soupescador` monorepo — see the root [README](../../README.md) for install/dev instructions shared across all workspaces.

## Development

```bash
npm run dev --workspace=@clube/mobile
```

This starts the Metro bundler. No business logic exists yet — see `docs/superpowers/specs/2026-07-13-mobile-app-scaffold-design.md` for what's in scope for this phase.
